Can this payment actually be allowed?

A payment can look normal to a fraud detector and still break the spending rules set by the customer. This demonstration shows the difference.

About this demonstration

Everything here is simulated. The merchant, products, customer, purchasing agent and spending rules are not real. The demonstration does not connect to a live payment network or customer account.

Run the demonstration

This runs the project's purchasing agent against a simulated merchant. Each proposed purchase is checked independently:

  1. Can the merchant accept the purchase?
  2. Does the fraud detector think it looks suspicious?
  3. Does the purchase follow the customer's spending rules?

The third check does not guess. It compares the purchase with the spending rules directly.

The point

A fraud detector asks:

“Does this payment look suspicious?”

The spending-rule check asks:

“Was this payment actually allowed?”

These are different questions.

This demonstration shows why a payment system may need both.
