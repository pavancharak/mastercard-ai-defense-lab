C3 Structural Prevention: Mandate Demo

Category C3 (Delegated Mandate Scope Abuse): a well-crafted mandate violation that can look statistically normal to a classifier. This page shows a real, captured run of mandate-demo/'s agent against a local synthetic merchant, with every proposed purchase run through three independent checks: the merchant API, Defend's real trained classifier, and a deterministic mandate-envelope check.

Honest framing

This is a local, from-scratch reimplementation of the architectural pattern used in Parmana's production mandate-binding system, not the real @parmana/sdk package, and never connected to any live Parmana infrastructure. All data (the merchant, products, mandate, agent) is synthetic. See mandate-demo/README.md for the full detail.
